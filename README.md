# Класс Matrix 

## Назначение и возможности
Базовая реализация класса двумерной динамической матрицы.

### Основные возможности:
* Три варианта инициализации (по умолчанию 0x0, квадратная единичная, прямоугольная с занулением).
* Безопасное управление динамической памятью через построчное выделение (`new[]`) и корректное освобождение (`delete[]`).
* Заполнение матрицы: значениями по умолчанию, случайными числами в диапазоне `[0; 99]` и ручным вводом с клавиатуры.
* Подсчет суммы всех элементов.
* Защита от некорректных параметров и выходов за границы через механизмы исключений С++.

## Компиляция и запуск

g++ -std=c++17 -Wall -Wextra main.cpp Matrix.cpp -o lab1
