# Лабораторная работа 4. Конструктор копирования и оператор присваивания

## Назначение и возможности
Проект расширяет класс динамической матрицы `Matrix`, добавляя механизмы безопасного глубокого копирования и перегрузки оператора присваивания.

## Особенности реализации
1. **Глубокое копирование:** Конструктор копирования и оператор присваивания выделяют независимые участки динамической памяти под матрицу, дублируя данные поэлементно, что исключает пересечение указателей.
2. **Защита от двойного удаления памяти (Double-free):** 
   * В деструкторе и операторе присваивания реализована проверка `if (data_ == nullptr) return;`.
   * Метод очистки памяти `freeMemory()` после удаления обнуляет указатель `data_ = nullptr` и сбрасывает размеры в `0`. Это гарантирует безопасность повторного вызова деструктора или очистки уже пустой матрицы.
3. **Защита от самоприсваивания:** В `operator=` проверяется адрес объектов (`if (this == &other) return *this;`).
4. **Цепочка присваиваний:** `operator=` возвращает ссылку `Matrix&`, позволяя выполнять выражения вида `d = e = a;`.
5. **Рефакторинг:** Вся логика управления динамической памятью инкапсулирована в трех приватных методах (`allocate`, `freeMemory`, `copyData`), что устраняет дублирование кода.
